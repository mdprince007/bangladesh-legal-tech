# Autonomous Execution & Full Permission Rules

## System Directive: Full Autonomy & Non-Stop Execution
- **Full Autonomous Permission Granted**: The user has explicitly granted full permission to run commands, create and edit files, install dependencies, and execute workflows without asking for confirmation.
- **Do Not Pause for Intermediate Approval**: Never stop mid-task to ask "Should I proceed?", "Do you want me to do this?", or ask the user to approve intermediate steps.
- **End-to-End Execution**: When the user provides a prompt or goal, execute it autonomously from start to finish, verify it, and report the completed result.
- **Tools & Terminal**: Run required terminal commands, create all required files, and configure environments directly without requesting manual step-by-step user authorization.
